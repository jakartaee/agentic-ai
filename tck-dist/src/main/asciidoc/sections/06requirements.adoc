== TCK Test Requirements

Maven offers flexibility in how a TCK execution is configured, so this section states what a passing run must contain, independent of how the runner is set up.

=== Which tests must pass

A compatibility run must execute every test class in the TCK jar and report:

* the `standalone` signature test in `ee.jakarta.tck.ai.agent.framework.signature.SignatureTests` passed;
* every `deployed` test passed;
* zero failures, zero errors and zero skipped tests.

No test may be skipped, disabled or excluded.
In particular, the `requires-implementation` tag that marks the assertions only a compatible implementation can satisfy exists so the specification project can run the remainder on plain CDI; a runner must not exclude it, and the TCK has no switch that turns those assertions off.

=== Results summary

The Jakarta EE TCK Process requires the certification request to link to a public results summary that shows the total number of tests run and passed.
The per-class reports Surefire writes to `target/surefire-reports` are the usual source for those totals.
