=== How this TCK was validated

Like other Jakarta EE TCKs, this TCK is run in full by a compatible implementation from that implementation's own repository; the specification repository builds the TCK but has no implementation to run it against.
The specification project's continuous integration additionally runs, on Weld Embedded, the part of the TCK that plain CDI can satisfy — everything not tagged `requires-implementation`, including the signature test.
That run is reproduced by `mvn clean install` at the root of the {APIGitSite}[specification repository] and is not a compatibility result.
