== Certify Compatibility

=== Runtime Tests and Signature Test Required

To certify compatibility with {APILongName}, run the TCK against your implementation and pass 100% of both:

* the {TCKTestPlatform} runtime tests and
* the signature test.

Both run in a single execution.
The signature test is an ordinary {TCKTestPlatform} test class in the TCK jar and runs alongside the other tests; no separate plugin execution or configuration is required.

=== Java SE Level

{APILongName} {APIVersion} requires Java SE {JavaVersion} or later.
The signature test resolves JDK types at the Java SE {JavaVersion} level whatever JDK runs the Test Server, so any JDK of that version or later produces the same result.

Use one JDK consistently for the whole certification run: the same `java -version` must apply to the Test Client, the Test Server and the results you publish.
